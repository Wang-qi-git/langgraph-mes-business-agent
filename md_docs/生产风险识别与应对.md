\# 生产风险识别与应对规范



版本：V1.0

适用：生产计划与风险管控



\## 1 风险总览



生产风险主要来自三个维度：\*\*物料、排程、设备\*\*。任一维度异常都会直接冲击交期。



\## 2 物料风险识别



| 风险类型 | 识别条件 | 风险等级 |

|----------|----------|----------|

| 投料未完成阻工 | 投料申请已发出但未完成 | 高 |

| 齐套校验不通过 | 排程前齐套校验失败 | 高 |

| 倒冲账实不一致 | 报工数量失真导致偏差 | 高 |

| 低值辅料短缺 | 线边库存低于安全阈值 | 中 |

| 物料不良隔离 | 触发物料隔离流程 | 中高 |



\### 应对措施



1\. \*\*投料未完成\*\*：立即联系仓库与投料组优先处理；必要时调整排程顺序；

2\. \*\*齐套不通过\*\*：启动紧急调拨或采购流程；若冻结期内无法解决，评估移出冻结期并重排；

3\. \*\*账实不一致\*\*：暂停相关工单报工，组织盘点核实；修正 BOM 或报工逻辑；

4\. \*\*物料不良\*\*：启动质量异常流程，评估替代料或供应商；必要时启动 8D。



\## 3 排程风险识别



| 风险类型 | 识别条件 | 风险等级 |

|----------|----------|----------|

| 资源冲突 | 同一设备同一时间被分配多个工单 | 高 |

| 冻结期内插单 | 紧急插单落入冻结期 | 高 |

| 工单延期预警 | 系统输出工单延期预警 | 高 |

| 换产频繁 | 同一设备短时间内多次换产 | 中 |

| 模具/工装冲突 | 多工单争用同一模具 | 中高 |

| 人员技能不匹配 | 排程工单所需技能与当班人员不符 | 中 |



\### 应对措施



1\. \*\*资源冲突\*\*：调度员人工干预，按交期优先级与可牺牲工单清单重新分配；

2\. \*\*冻结期内插单\*\*：启动紧急插单流程，识别可牺牲工单，报生产经理审批；

3\. \*\*工单延期预警\*\*：逐单分析延期原因（缺料/设备/人员），制定追赶计划；

4\. \*\*换产频繁\*\*：优化排程批次，合并同模具工单；评估增加模具或外协可能性。



\## 4 设备风险识别



| 风险类型 | 识别条件 | 风险等级 |

|----------|----------|----------|

| 关键设备故障 | 瓶颈/关键设备非计划停机 | 高 |

| 设备带病运行 | 告警未处理但仍在运行 | 中高 |

| 预防性维护冲突 | 计划保养与排程工单时间重叠 | 中 |

| 备件短缺 | 关键备件库存低于安全库存 | 中高 |

| OEE 持续偏低 | 设备 OEE 低于目标值 | 中 |



\### 应对措施



1\. \*\*关键设备故障\*\*：立即通知维修团队，启动备用设备或外协预案；

2\. \*\*设备带病运行\*\*：安排计划性停机检修，避免非计划停机扩大；

3\. \*\*备件短缺\*\*：紧急采购或调拨关键备件；评估替代备件可行性；

4\. \*\*预防性维护冲突\*\*：与排程协调，将保养窗口移至非瓶颈时段；

5\. \*\*OEE 持续偏低\*\*：组织设备、工艺、生产联合分析，制定改善措施。



\## 5 风险优先级排序



| 优先级 | 风险类别 | 典型风险点 | 响应时限 |

|--------|----------|------------|----------|

| P0 紧急 | 缺料 | 投料未完成阻工、齐套不通过 | 立即处理 |

| P0 紧急 | 设备 | 关键设备故障 | 立即处理 |

| P1 高 | 排程 | 资源冲突、冻结期内插单 | 24 小时内 |

| P1 高 | 缺料 | 倒冲账实不一致 | 24 小时内 |

| P1 高 | 排程 | 工单延期预警 | 24 小时内 |

| P2 中高 | 设备 | 备件短缺、设备带病运行 | 48 小时内 |

| P2 中高 | 缺料 | 物料不良隔离 | 48 小时内 |

| P3 中 | 排程 | 换产频繁、模具冲突、技能不匹配 | 本周内 |

| P3 中 | 设备 | 预防性维护冲突、OEE 偏低 | 本周内 |

| P4 低 | 缺料 | 低值辅料短缺 | 本周内 |



\## 6 数据采集维度



| 维度 | 数据来源 |

|------|----------|

| 线边库存 | MES 投料扫码记录 |

| 倒冲物料库存 | MES 报工自动扣减 |

| 齐套状态 | ERP 工单/BOM + MES 库存 |

| 排程模式 | MES 内置简易有限能力排程 |

| 设备运行状态 | SCADA 设备日志 |

| 设备综合效率 | SCADA/OEE 系统 |

| 故障报警记录 | SCADA 报警日志 |

| 备件库存 | ERP 备件库存 |



\## 7 风险评审机制



\- \*\*日评审\*\*：生产早会，聚焦 P0/P1 风险；

\- \*\*周评审\*\*：生产例会，复盘本周风险与处置效果；

\- \*\*月评审\*\*：管理层评审，识别系统性风险与改善方向。
